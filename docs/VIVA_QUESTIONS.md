# DanceSphere — quick viva preparation

1. **What is a SPA?** A Single Page Application updates its view without reloading the entire document for every navigation.
2. **What is JSX?** A syntax extension that lets React components describe UI using HTML-like syntax inside JavaScript.
3. **What are props?** Inputs passed from a parent React component to a child component.
4. **What is state?** Data a component tracks; changing state triggers a render.
5. **What does `useEffect` do?** It runs side effects such as loading data or registering event listeners.
6. **What is a REST API?** A web interface that exposes resources through HTTP methods such as GET, POST, PUT, PATCH and DELETE.
7. **Why use prepared statements?** They separate SQL structure from user-provided values and help prevent SQL injection.
8. **Why hash passwords?** A hash lets the system verify a password without storing the original password.
9. **What is middleware in Express?** A function that runs during the request-response cycle and can validate, modify or reject a request.
10. **What is a session in PHP?** Server-managed state associated with a visitor across requests.
11. **What does `filter()` do?** It creates a new array containing elements that pass a condition.
12. **What is semantic HTML?** Elements such as `header`, `nav`, `main` and `footer` describe the meaning and structure of content.
13. **What is CSS Grid?** A two-dimensional layout system for arranging content in rows and columns.
14. **Why separate frontend and backend?** The frontend handles presentation and interaction; the backend validates requests, enforces permissions and accesses data.
15. **What is role-based access control?** Permissions are granted based on a user's role, such as student, owner or admin.
